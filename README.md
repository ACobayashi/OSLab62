# Lab3：中断与异常处理

## 实验内容

在 Lab2 内核启动、物理内存管理和分页的基础上，完善 uCore RISC-V64 内核的中断与异常处理。实验包括 Trap 入口、上下文保存与恢复，以及汇编和 C 处理函数之间的调用与返回。

实现持续的时钟中断、计数输出与自动关机，处理非法指令和断点，并按实际指令长度更新异常返回地址。结合中断关闭与开启、原子操作和 stvec 模式分析，通过内核测试、评分脚本和 QEMU/GDB 调试，验证 Trap 分发、寄存器与栈恢复及异常后的继续执行。

## 主要验证内容

- Trap 入口传参、帧布局、通用寄存器与栈指针恢复
- 持续时钟中断、计数输出及达到阈值后的自动关机
- 16/32 位非法指令与断点的 EPC 更新及实际返回
- 软件中断、未知中断和其他异常的构造帧兜底验证
- QEMU/GDB 现场调试，以及三人实现整合后的运行与评分
