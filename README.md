# Operating System Labs

本仓库用于 uCore on RISC-V64 操作系统实验。

## 目录

```text
.
|-- code/                 # 实验一源代码
|-- report/
|   |-- images/           # 测试结果截图
|   |-- prompt.md         # 本实验使用的全部提示词
|   `-- report.md         # 实验报告模板
|-- .gitignore
`-- README.md
```

本分支名为 `lab1`。后续每次实验分别建立 `lab2`、`lab3` 等分支，并保持相同的 `code/`、`report/` 结构。
