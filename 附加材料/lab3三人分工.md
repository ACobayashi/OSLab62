# Lab3 三人分工

按“功能模块一一人、功能模块二两个函数各一人”划分，并结合原理分析、测试和报告平衡工作量。报告严格对应《实验报告模板.md》，总大纲为 [report/汇总.md](../report/汇总.md)，个人文件沿用相同章节编号和标题。

## 2410673 韩羽宸

- **设计功能一的 SPEC 和 prompt。** 根据已有 `SAVE_ALL`、`struct trapframe` 和 RISC-V 调用约定，明确上下文布局、恢复前后状态、`sp` 的特殊处理、参数传递及允许修改的范围，说明各项约束为什么这样写。
- **完成 `RESTORE_ALL`、`__alltraps`。** 实现与保存布局对应的上下文恢复，将当前 Trap frame 正确传给 `trap()`，衔接 `__trapret` 和 `sret`，形成进入、处理、恢复、返回的完整流程。
- **分析上下文和返回机制。** 解释通用寄存器与 CSR 的保存位置、栈的变化、`sscratch` 的作用，以及 `sepc`、`sstatus`、`SPP/SPIE` 与返回执行状态的关系；区分硬件自动处理和软件保存恢复的部分。
- **验证入口与恢复。** 检查 Trap frame 传参、寄存器与栈指针恢复、处理后继续执行；与林子媛共同核对断点返回，保存命令、预期与实际结果及必要截图。
- **完成对应报告并统稿。** 填写基本信息、**4.1 功能模块一、5.1 上下文恢复验证、5.5 报告整理与最终提交检查**，以及本人实验环境和第六部分总结。依据各人已完成的正文按编号合并，核对手册全部报告要求和最终提交内容。

个人报告：[2410673_韩羽宸.md](../report/2410673_韩羽宸.md)。

## 2410933 马禹翔

- **设计中断处理的 SPEC 和 prompt。** 明确中断类型识别、时钟事件续设、计数与输出规则、关机阈值及依据、其他中断提示和未知中断的兜底行为，并将接口和输出要求写进提示词。
- **完成 `interrupt_handler()`。** 正确处理 `IRQ_S_TIMER`：设置下一次事件，每次增加 `ticks`，按规定间隔输出统计，到达规定条件后关机；补齐其他中断类型的提示和未知类型的 `print_trapframe(tf)` 输出。
- **分析时钟、中断保护和整体逻辑。** 结合 `clock.c`、`intr.c`、`sync.h`、`atomic.h` 解释时间基准、中断使能、临界区及原子位操作，回答 `do…while(0)` 思考题；梳理初始化、Trap 入口、分类处理和返回的依赖与执行顺序。
- **验证中断并组织整体测试。** 检查时钟持续触发、计数输出、关机和兜底处理，区分真实中断与构造 Trap frame 的测试。合并后运行 `make qemu`、`make grade`，保存整体运行证据和一份最终评分截图；发现问题交由相应负责人修复。
- **完成对应报告。** 填写**第三部分整体逻辑、4.2 中断处理、4.4 中断关闭开启练习、5.2 中断验证、5.4 整体运行与最终评分**，以及本人实验环境和第六部分总结。

个人报告：[2410933_马禹翔.md](../report/2410933_马禹翔.md)。

## 2410936 林子媛

- **设计异常处理的 SPEC 和 prompt。** 明确非法指令、断点和其他异常的分类，规定提示格式、指令长度判断依据、`tf->epc` 更新规则及返回后的预期行为，说明为什么不能统一使用相同的 EPC 偏移。
- **完成 `exception_handler()`。** 处理非法指令和断点异常，输出要求的信息并正确更新 EPC，使返回后继续执行；其他未要求恢复的异常使用 `print_trapframe(tf)` 兜底。
- **分析异常和权限机制。** 说明同步异常与异步中断、M/S/U 特权级、OpenSBI 委托及 `scause/sepc/stval` 的作用；结合 `idt_init()` 说明 Direct 模式入口设置，回答 `stvec` 模式编码的向后兼容思考题。
- **验证异常处理。** 记录触发指令、实际长度、异常前后 EPC、输出和恢复执行情况，确认不会反复执行同一异常指令；验证其他异常的兜底输出。与韩羽宸共同检查断点返回及上下文恢复，注明测试方式和证据。
- **完成对应报告。** 填写**第一部分实验目的、4.3 异常处理、4.5 stvec 思考题、5.3 异常验证**，以及本人实验环境和第六部分总结。

个人报告：[2410936_林子媛.md](../report/2410936_林子媛.md)。

## 三人共同交付要求

- **报告材料齐全。** 每人按模板提交模块功能与核心函数理解、SPEC 和 prompt 的设计过程、实际最终提示词、真实 bug 的触发与原因、修正和复测结果；分析练习也说明 SPEC 和实际分析方法。以 Markdown 文字说明为主，截图配说明，不编造问题或通过结果。
- **总结覆盖两类知识。** 各自说明实验知识与对应 OS 原理知识各自的含义、联系和差异，并列出重要但本实验未覆盖的知识；补充本人真实的 AI 协作经验。
- **接口与合并保持一致。** 保留已有 `SAVE_ALL`、Trap frame 布局和接口签名，按题目限定范围修改。马禹翔、林子媛分别合并 `trap.c` 中本人的函数区域；三人共同核对 Trap frame、EPC 和返回状态的衔接，不改动评分条件。
- **按手册完成提交。** 各自保留 `lab3` 注释，完成后将 `YOUR CODE` 换为实际实现者学号，共享位置注明贡献并填齐实现。图片放在 `report/images/学号/`；韩羽宸核对最终报告位于本次实验目录内，代码与报告一起提交并推送到小组 GitHub 的 `lab3` 分支，记录提交版本与时间，确保按时提交。
